# Ilustrações do Horizonte

Geradas com a ferramenta integrada `imagegen` em 2026-09-14.

- `goals-empty.png`: ilustração para a tela Metas quando não há metas cadastradas.
- `trips-empty.png`: ilustração para a tela Viagens quando não há viagens cadastradas.

PNGs com transparência, incluídos localmente para uso offline. As imagens são decorativas; os textos e botões das telas continuam fornecendo as informações acessíveis. Exibição com `contain`, tamanho de 180 × 180 e largura limitada ao contêiner. As cores seguem o laranja padrão do app; não são recoloridas pela preferência de tema.
